# 學習與評量

[文件入口](../README.md) · [使用指南](usage.md) · [教材處理](materials.md)

## 學習與題組身分

同一使用者、教材與知識結構版本對應持久 StudySession。不同觀念可各自保留題組，同一 session／觀念只保留一組進行中的題組；讀取不建立 session 或重算答案。

題組的 owner、知識結構版本、觀念及成員決定作答授權，導覽焦點不改變授權範圍。

## 準備與發布

題數由觀念中可出題的重點決定。題組保存計畫、執行快照、逐題狀態與 lease；worker 在交易外生成候選，驗證後保存並發布。

新題組使用 `source-span-single-choice/v3`：題幹、選項與解析均以繁體中文生成，英文技術術語可保留原文。`correct_answer` 是忠實翻譯；私有答案保存繁中 `rationale` 與原文 `source_quote`，引句必須是所引 Evidence 的連續子字串。解析須說明正確選項的理由與其他各選項為何不對，四個選項不能有兩個合理答案。獨立解題依繁中選項的意思對照原文。已存 v1／v2 題目與在途題組的封存 lock 保持原生成、驗證及讀取行為，不重寫既有資料。

生成器提出候選；獨立檢核只取得來源、題幹與重排選項，不接收答案鍵。發布要求唯一答案與候選正解一致、來源有效且不重複已發布題目。通過正確性檢查後才依品質提示排序，干擾選項較弱不等於無安全題。

公開 API 不暴露準備中的題目或私密答案。失敗可重試未完成題；已有可用題時可選部分發布，其餘重點維持未檢測。每組使用建立時封存的模型設定，調整設定不改寫已保存題組。

## 交卷

提交包含全部已發布題目的選項、expected_set_version 與 Idempotency-Key。少答、重複成員、無效選項或範圍不符都會拒絕整次提交。

答案、事件序號與題組完成狀態在同一交易保存，失敗全部回滾。後端依私密答案評分；相同意圖重播不重複計分，也不覆寫已保存答案。版本衝突須先同步，回應遺失可查回結果。

## 錯題補強與掌握

補強題組綁定原初篩，只包含仍待改善的重點；每輪需明確開始，有進行中的同觀念題組時先接續。

| 重點狀態 | 意義 |
| --- | --- |
| diagnostic_pass | 初篩答對 |
| needs_review | 初篩答錯，最新補強尚未答對 |
| remediation_pass | 補強答對 |
| unanswered | 未作答 |
| unavailable | 未發布題目 |

未作答或生成失敗不算答錯，也不算通過。評量結果依進行中題組、待改善與未檢測重點投影為 in_progress、needs_review、passed 或 incomplete。

補強答案標為 assisted，計入改善但不增加獨立掌握證據。掌握要求每個 Claim 具備不同的合格正確題與最新正確作答，詳見 [learning_states.py](../backend/src/learning_adaptation/learning_states.py)。

## 恢復與版本承接

Progress 與 resume 使用同一 DB snapshot，核對 session、run、知識結構版本、題組成員與事件序號。URL 可定位原題組；讀取、刷新與重新登入不產生題目或答案事件。

下一步由後端進度決定，前端提交 guidance_revision 套用操作。更新教材後，來源、文字及區塊一致且可唯一匹配的重點能承接證據；變更或匹配有歧義時不承接。

承接不複製答案事件，也不修改原題目、正誤、時間或版本。原題組仍依其固定版本讀取。

## 競賽版介面與匯出

學習頁將今天的概念、學習目標及測驗紀錄分開呈現；測驗紀錄依待加強、已掌握與全部分類。結果頁右側保留作答紀錄，可回看已保存的題組；讀取不改寫作答與來源綁定。

概念卡使用側邊清單選卡，匯出以教材名稱與卡片順序命名；知識地圖只匯出概念大綱 Markdown。卡組與 Podcast 名稱上限為 40 字，既有資料由 0031_content_names_40.sql 處理，原 0030 保留。

Podcast 略過仍無法通過來源核對的段落，保存 omitted_content；不因省略比例拒發其餘已核對段落，整集沒有可保留段落才失敗。

Podcast 的 ready 與 completed_episodes 依已完成音訊計算；講稿完成後排入配音，音訊完成後排入字幕對齊，勾選影片時另排影片。先前只產講稿的 ready 節目提供閱讀及 Markdown 匯出，不請求不存在的音訊、影片、時間軸或收聽進度。

## 學習回饋

升級與新徽章由伺服器一次領取，同時取得時先顯示升級。新徽章顯示為左下角浮動通知，不推動版面或移動焦點；6 秒後收起，也可按「關閉」或「查看」前往成就頁。

測驗結果頁的解析優先顯示 API feedback.rationale；只有v2／v3題目回傳保存的解析，v1舊題feedback.rationale為空字串，維持對應重點原文。來源按鈕維持回查教材。

## AI BOT 回答驗證與診斷

每次送出或手動重試的回答工作，若遇到 `VOICE_ANSWER_INVALID`，會自動重新生成並核對一次；兩次仍未通過才顯示失敗。來源與回答驗證條件不變，取消、語音轉寫及供應商連線失敗不套用此重試。

被拒絕的模型候選與具體驗證原因保存在 `STUDYDY_ARTIFACT_ROOT/failures` 私有診斷，檔案0600、目錄0700，沿用30日清理。首輪失敗的紀錄在第二輪成功後仍保留；公開問答API只提供已驗證回答與固定錯誤碼，不提供候選或診斷，也不保存請求認證標頭。
